# Jobs To Be Done — коротко

Формула работы: **Когда [ситуация], я хочу [мотивация], чтобы [ожидаемый результат].**

- Работа ≠ функция. «Медитация 10 минут» — функция; «успокоиться перед сном, когда голова
  кипит после работы» — работа.
- Ищи **ситуацию-триггер**: когда именно человек вспоминает о продукте.
- Конкуренты по работе шире конкурентов по категории: для «уснуть» конкурируют подкасты,
  сериал, алкоголь, «ничего».
- Силы прогресса: толчок (боль сейчас), притяжение (образ нового), тревога (страх нового),
  привычка (инерция старого). Уход пользователя = тревога+привычка сильнее толчка+притяжения.

Источники работ: интервью (лучше всего — о недавнем конкретном случае), отзывы в сторах,
поисковые запросы, форумы. Синтетические респонденты — только для генерации гипотез о работах.
