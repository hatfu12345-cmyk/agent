# План проверки

| Поле | Что писать |
|---|---|
| Ожидаемое изменение | метрика, направление, величина (как ПРОГНОЗ + допущения) |
| С чем сравниваем | A/B (контроль), период до/после (с учётом сезонности), бенчмарк категории |
| Срок наблюдения | сколько ждать, чтобы метрика созрела (D7 — не раньше чем через 7 дней после последнего установщика в когорте) |
| Объём | минимум пользователей в группе (грубо: для разницы 3 п.п. при базе 15% — ~2 000 на группу) |
| Критерий решения | успех / провал / неясно → что делаем в каждом случае |
| Нежелательные последствия | что может ухудшиться (отписки от пушей, удаления, жалобы, выручка) + порог остановки |

Правила: одна главная метрика; ограничители заранее; не «подглядывать» и не останавливать
тест при первом хорошем результате; результат — новый источник и пересмотр решения (этап 6).
