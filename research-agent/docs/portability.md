# Переносимость

Всё состояние — в обычных файлах Markdown/CSV, поэтому проект переносится копированием папки
(или через git) в любую среду.

| Среда | Что подхватит правила | Примечание |
|---|---|---|
| Cursor | `.cursor/rules/agent.mdc` → `AGENTS.md` | MCP — `.cursor/mcp.json` по образцу `mcp.example.json` |
| Claude Code | `CLAUDE.md` → `AGENTS.md`; навыки, субагенты, хуки из `.claude/` | `.mcp.json` по образцу |
| Codex, OpenCode, Copilot, Windsurf | `AGENTS.md` (стандартное имя) | навыки читать как обычные `.md` |
| GigaCode, Кодик и другие | попросите: «Прочитай AGENTS.md и следуй ему» | |

## Перенос задачи в середине работы
1. Скопируйте папку (или `git push` / `git pull`).
2. В новой среде: «Прочитай AGENTS.md, продолжи активный проект».
3. Агент выполнит `agent.py status` и продолжит со `next_step` из `state.md`, не повторяя закрытые этапы.

Привязки к конкретной модели нет: стоимость считается по `config/pricing.json` — добавьте туда свою модель.
