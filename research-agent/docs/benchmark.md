# Сравнение с исходным способом

Цель — измерить, насколько агент быстрее, дешевле или точнее, чем (а) аналитик вручную и
(б) обычный чат с ИИ, и какой ценой.

## Протокол
1. Возьмите 3 задачи разного типа (продуктовая, коммуникационная, пересмотр решения) с одинаковыми материалами.
2. Выполните каждую тремя способами: агент (этот репозиторий) / обычный чат с той же моделью и тем же запросом / аналитик вручную.
3. Замерьте:

| Метрика | Как мерить |
|---|---|
| Время до результата | минуты от запроса до финальной стратегии (включая ответы человека) |
| Стоимость | `agent.py cost report` (модель + поиск + время человека по `config/pricing.json`) |
| Прослеживаемость | % существенных утверждений со ссылкой на источник |
| Точность | % утверждений, подтверждённых проверкой источника (субагент `source-checker` + выборочно человек) |
| Полнота | прошёл ли результат `check --strict` (варианты, статус-кво, возражения, пробелы, план проверки) |
| Доработка человеком | минуты правок до состояния «можно показывать руководителю» |
| Продолжение после перерыва | удалось ли продолжить в новом чате без повторов (да/нет) |
